# 平衡球控制算法说明

系统：MaixCAM2 视觉检测 → UDP 广播 → ESP32-S3 100Hz 控制 → Emm42_V5 步进电机 → 摆杆倾角控球

控制律总输出：

```
u = trim + Kp·error + Kd·speed + Ki·boost + kick
```

其中 `error = 球位置 - 目标位置`，`speed` 为球速估计。下面逐项说明。

---

## 1. PD 主控制（比例-微分）

最基础的负反馈：误差越大摆角越大（Kp），球滚得越快刹车越狠（Kd）。

- `KP_DEG_PER_CM = 0.6`，`KD_DEG_PER_CMS = 0.5`（近端温和增益）

**球速估计**：ESP32 端维护 16 点位置历史环形缓冲，取约 100ms 基线做差分求速度，并限幅 ±40 cm/s。比单帧差分抗检测抖动。

## 2. 增益调度（Gain Scheduling）

问题：单一组增益要么远端太慢（T3 限时 5s），要么近端过冲振荡。

方案：按误差大小切两组增益：

| 区域 | 条件 | Kp | Kd | 目的 |
|------|------|----|----|------|
| 远端 | \|error\| > 2cm | 1.0 | 0.3 | 冲得快、少刹车，抢时间 |
| 近端 | \|error\| ≤ 2cm | 0.6 | 0.5 | 温和求稳 |

曾经的病症：中途 2 秒停顿——PD 平衡速度 v ≈ (Kp/Kd)·\|error\| 在半路降到静摩擦阈值以下，球停住。远端减小 Kd 解决。

## 3. 静摩擦补偿（三件套）

钢球在水管里静摩擦大，纯 PD 在小误差时给的角度顶不动球。三个机制配合：

### 3a. Kick 前馈
球卡住（\|speed\| < 1.5 cm/s）且误差够大（> 0.8cm）时，立即加 ±2° 突破角；球一动就撤。误差太小不 kick，防止在目标附近来回拍打。

### 3b. Boost 破卡积分
卡住时误差快速积分（速率 3°/(cm·s)，限幅 8°），持续加大顶角直到破卡。
**关键防过冲设计**：球速一旦超过 4 cm/s（已滚动），boost 立刻清零——积分储存的能量不带进飞行阶段，只留 PD 管飞行。这解决了经典的「积分储能→破卡→火箭式过冲」极限环（曾出现 -7 ↔ -3 来回摆）。

### 3c. CREEP 步进定位（近距离顶到动为止）
近端（\|error\| ≤ 2cm）且球卡住时，不用积分，改用"顶-撤"节奏：

```
球停稳 → 顶角 ±creep_pulse（初始2°）
       → 每 300ms 没动就 +1°（上限 6°）
       → 球一挪动 ≥0.15cm 立即撤角回 trim，滑行
       → 停稳后评估：这一击滑过 1.2cm？下次减 0.5°
       → 重复，直到进入死区
```

本质是**自适应脉冲宽度调节**：即顶即撤，几乎不储能，天然不过冲。取代了早期"盲发固定 150ms 脉冲"（脉冲结束时球还没破卡，无效）。

## 4. 驻留积分 trim（弯管自适应，最后加的关键一环）

问题：水管是弯的 + 支架下沉，摆角 0° 在不同位置**不是水平**。实测球停在 -5 后以 0° 保持会慢慢漂回 -2.5；且每次上电手动摆平也做不到真水平。

方案：`trim` 学习**当前目标位置的持衡角**：

- 球在目标 ±2cm 内（且非顶角期间）持续积分：`trim += 1.5 · error · dt`，限幅 ±4°
- 管子弯 → 球往低处漂 → 误差累积 → trim 顶住坡度 → 漂移收敛
- **换目标清零重学**：+5 和 -5 处的持衡角完全不同
- HOLD（到位且静止）时主动保持在 trim 角上，**不回 0°**

同时解决了上电零偏问题：无论开机时摆杆是否真水平，trim 会自动学出补偿。

早期版本曾直接从 cmd_angle 学 trim，因 cmd_angle 含 PD/kick 分量导致正反馈棘轮发散（trim 一路涨到 7°，球被打飞），改为纯误差积分后解决。

## 5. 状态机（100Hz 控制任务每周期选一个模式）

```
断联/丢球超时 300ms ──────────────→ SAFE  匀速 15°/s 回平
│
├ |error|≤0.3 且 |speed|≤0.8 ─────→ HOLD  保持 trim 持衡角
├ |error|≤2   且 |speed|<1.5 ─────→ CRP   顶角等球动
│                    (顶角撤了) ──→ GLD   滑行/等停稳
└ 其余（远端或球在飞） ──────────→ PD    增益调度 PD + boost + kick
```

## 6. 输出整形（保护措施）

- **摆角限幅**：控制量 ±10°（给 trim 留余量），机械硬限 ±20°
- **变化率限幅**：80°/s——防止摆杆猛拍把球弹飞（丢锁重连时尤其重要）
- **脉冲去重**：pulses 没变不重发串口指令，减轻总线负担
- 角度 → 脉冲：`pulses = angle/360 × 3200`（200 步 ×16 细分）

## 7. 视觉端（MaixCAM2）

- YOLOv5 检测球，限定在允许条带内取最高分目标
- 像素 → cm：以画面中心为 0，左右各 12 格线性映射
- **EMA 位置滤波**：α = 0.65（速度估计放在 ESP32 端做，避免双重滤波延迟）
- T3 状态机：目标 +5 → 球过 4.2cm 保持 100ms（防毛刺）→ 切目标 -5 → 误差 ≤1cm 保持 500ms → 完成计时定格
- UDP 广播 `B,seq,ball_cm,target_cm`，丢球发 `N,seq`；ESP32 收不到 300ms 自动回平

## 调参速查

| 症状 | 动哪个参数 |
|------|-----------|
| CRP 破卡等 >1s | `CREEP_PULSE_MAX_DEG` 6→8 |
| GLD 一击滑过 >1.2cm | `CREEP_MOVED_MIN_CM` 0.15→0.1 |
| 到 -5 后仍慢漂 | `KI_SLOW_DEG_PER_CM_S` 1.5→2.0 或 `TRIM_CLAMP_DEG` 4→6 |
| T3 超 5s | MaixCAM 端 `T3_ARRIVE_CM` 4.2→3.8 |
| 远端过冲大 | `KD_FAR_DEG_PER_CMS` 0.3→0.4 |
